# FastSchool（截图分割版）说明文档

本文档面向 Demo 使用与二次开发，解释当前“截图分割”链路的输入输出、关键逻辑与已知限制。

## 1. 产品定位

- 目标：把 PDF 试卷转换成“实时互动答题”。
- 策略：不依赖 OCR 分词与语义理解，直接使用 PDF 的版面坐标（bbox）进行题干/选项的截图裁剪。
- 适用：题干与选项在版面上规整、选项以 `A.`/`B.`/`C.`/`D.` 标识的试卷（尤其是标准考试卷）。

## 2. 使用方式

### 启动

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

### 访问

- 浏览器打开：`http://localhost:8000/`
- 上传 PDF 后进入答题界面
- （可选）上传 txt 答案卡，交卷时自动判分：每行一条，格式为 `题号 选项字母`，如 `1 B`。
  示例见 `samples/answer_key.txt`，示例试卷见 `samples/demo_paper.pdf`。

## 3. 接口说明

### `POST /upload_screenshot`

- 入参：`multipart/form-data`，字段名 `file`，仅支持 `.pdf`
- 出参：
  - `success`: 是否成功
  - `source`: 固定为 `screenshot`
  - `total`: 题目数量
  - `questions`: 题目数组
    - `id`: 题号（来自 `1.`/`2.` 等）
    - `page`: 页码
    - `parsed.stem_image`: 题干图片（base64 data-url）
    - `parsed.options.A.image` 等：选项图片（base64 data-url）

### `POST /upload_answerkey`

- 入参：`multipart/form-data`，字段名 `file`，支持 `.txt`（`.pdf/.png/.jpg` 会存储但不解析）
- txt 每行一条：`题号 选项字母`（如 `1 B`、`2: C`），解析出 `{题号: 字母}` 字典
- 出参：`success` / `id`（判分时前端凭此 id 关联）/ `parsed` / `count` / `answers`
- 判分在浏览器端完成：交卷时逐题比对用户选择与 `answers`，弹窗即时反馈，
  结束页汇总正确题数与错题（可点击错题跳回重做）

### `POST /upload`（已废弃）

- 返回明确错误，提醒刷新页面并改用 `/upload_screenshot`

## 4. 核心实现

### 4.1 坐标提取与截图裁剪

实现文件：[pdf_segmenter.py](file:///home/tbtb/projects/FastSchool/pdf_segmenter.py)

- `page.get_text("dict")` 提取行级文本与 bbox
- `page.get_text("words")` 用于在“一行多选项”场景下定位 `A.`/`B.` 的真实 x 坐标，从而更精确切分每个选项区域
- `page.get_pixmap(matrix=Matrix(zoom, zoom))` 生成页面渲染图，再按 bbox 裁剪为 PNG

### 4.2 分割策略（当前启发式）

- 题目开始：匹配 `^\d{1,3}[.)、]`
- 选项标记：匹配 `A.`/`B)`/`C、` 等
- 题干合并：只允许合并与上一行距离较近的行（避免把别的段落合进去）
- 选项续行：只有在“明显缩进 + 行距很小”时才合并到同一选项

可调参数（在 `pdf_segmenter.py` 顶部）：

- `PAD`: 裁剪外扩边距（越小越紧）
- `STEM_LINE_GAP`: 题干续行最大行距
- `OPTION_LINE_GAP`: 选项续行最大行距
- `INDENT_MIN`: 选项缩进判定阈值

## 5. 已知限制与下一步

### 已知限制

- 双栏版式、多行跨栏的题目可能需要更复杂的版面分析。
- 题号/选项标记不标准（例如没有 `A.`）时，需要扩展规则或增加手工校正 UI。
- “题干/选项”并不一定与“行”严格一致，当前策略通过行距/缩进约束尽量避免串行。
- 扫描版（纯图片）PDF 无文字层，不适用本方案（早期 OCR 方案见 `legacy/`）。

### 目录约定

- `samples/` — 示例试卷与答案卡
- `legacy/` — 黑客松时期旧原型（OpenCV 切割 / OCR / Streamlit 前端），主应用不依赖

### 下一步建议

- 加入“人工校对”步骤：展示识别到的题干/选项截图，允许用户拖拽调整 bbox。
- 引入列检测：按 x 分布聚类，先判断单栏/双栏，再做 bbox 合并。
- 题型扩展：支持完形填空、匹配题、表格题等。
